# 纸艺实现

模板使用无第三方依赖的 CSS 3D。默认纸面 600×440、90°展开，仅是暖色横开起点，需根据批准方案调整。不能只换背景就宣称匹配所有结构参考。

背页绕折线转动；前景人物、中间装饰各绕底边转动。平行支撑条连接人物背部与背页，附着点随开合角度变化，闭合时平铺。正反面纸色、纸边、折痕和接触阴影都应完整；背面不显示正面镜像。

图层参数 x、pivot、width、height 以纸面坐标表示。默认向前倒伏：pivot + height <= card.depth，x >= 0，x + width <= card.width。其他折法需重算。支撑位置随主体 pivot、高度和宽度调整。V 折、阶梯折等不同结构需要修改模板，不能只改 z-index。

前景主角不被装饰挡脸；后层祝福清晰。轻微纸纹、纸张厚度与层间阴影，避免塑料质感。图像必须是 alpha 剪纸。

拖动超过阈值才旋转，不能误开合；手动拖动停止自动旋转。全周水平旋转、上下俯仰、缩放和重置可用。动画结束精确落位，指针取消可恢复。彩纸只在开到指定角度触发一次，可重放但及时清理；减少动态效果时即时开合并禁用粒子。

360°是纸片与支撑结构查看，不是人体圆雕。该网页不作为实体刀模生产文件。

## 充盈构图与贴纸层
默认追求丰富而不是稀疏。规划背景装饰场、左右两组中型主题物件、前景主体与底座点缀，形成大小错落的簇群。用彩带、箭头、圆圈和动态线条连接空隙，用花鸟、爱心、闪光和小道具补充节奏；这些只在用户授权类别内使用。

可作为起点：3–5个中大型装饰群、8–16个小点缀，背景/中景/前景/底座均有内容；这不是硬性数量，手机视图以清晰度为准。不要为了填满而遮挡脸、手、躯干关键轮廓或生日文字。大空区应有有意的视觉作用；若没有，则补入主题元素。

人物贴纸的白色描边和柔和阴影使用已确认资产；微悬浮由前景视觉子层实现（约1–3px、4–6秒缓慢周期），不移动纸艺铰链或支撑。开合时冻结，完全打开后启用，减少动态效果时关闭。避免浮动导致连接断开或装饰穿过人物。
